## 完整说明

```
Namewise renames a whole folder of files in seconds, using simple rules you can preview before anything changes.

RULES
• Number in order: Trip_001, Trip_002, Trip_003… choose the start number, digits and separator, ordered by name or date
• Add date: put the date each file was last changed in front of its name, or rename files to date + number
• Prefix and suffix: add text before or after every name
• Find and replace: swap or remove a piece of text in many names at once
• Change case: lowercase, UPPERCASE or Title Case

PREVIEW, THEN RENAME
• See every old name next to its new name before you start
• Untick any file you want to leave alone
• Names that would clash, or contain characters the phone can't use, are flagged so nothing is overwritten
• File extensions are always kept

UNDO ANYTIME
• Every batch is saved in Recent renames
• Open a batch to check what changed, and undo the whole batch with one tap

PRIVATE AND SIMPLE
• Works on the folders you choose in the Android folder picker. No storage permission, no account
• Everything happens on your phone. Your files and names are never uploaded

Namewise is free and supported by ads.
```
